# SQL Analysis

This folder contains the SQL part of the Profit Leak Analysis project.

The SQL analysis recreates the main findings from the Excel exploration using structured queries.

## Objectives

- Create a database for the Global Superstore dataset
- Import the Orders, Returns and People tables
- Analyse sales, profit and profit margin by category
- Identify unprofitable sub-categories
- Investigate the relationship between discounts and profit margin
- Analyse where table-related losses are concentrated by region

## Main Business Questions

1. Which product categories generate the most sales and profit?
2. Which categories have the weakest profit margins?
3. Which sub-categories are causing profit leakage?
4. Are high discounts linked to negative margins?
5. In which regions are Tables losing the most money?
